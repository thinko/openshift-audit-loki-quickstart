Audit LokiStack — Query Bookmarks

Pre-built LogQL queries for the OpenShift Console Logs view, logcli, and Grafana Explore.

How to use

  1. Set your Console URL above (saved in your browser).
  2. Click Copy to copy the LogQL query to your clipboard.
  3. Click Open in Console to jump directly to the Logs view with the query loaded.
  4. In the Console: set the log type to audit, then click Show Query and paste.
  5. For queries with | json or | line_format: these require logcli or Grafana Explore (the Console query box only supports stream selectors).
