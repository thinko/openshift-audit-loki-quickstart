How to use

  1. Set your Console URL, Grafana URL, and global query variables above (all saved in your browser).
  2. Queries that need a username, namespace, or resource name use the global defaults above. You can override per-query using the inline fields shown when you expand a card.
  3. Copy — copies the resolved query (with your variables filled in) to your clipboard.
  4. Open Logs / Open Metrics — opens the OpenShift Console with the resolved query and time range.
  5. Explore — opens Grafana Explore with the resolved query.
  6. The Console query box only supports stream selectors. For | json and | line_format queries, use Explore in Grafana.
